# Born2beRoot

A short, beginner-friendly overview of the **42 Born2beRoot** system-administration project.

## 📘 Introduction
Born2beRoot teaches the fundamentals of server setup and security by guiding you through the creation and configuration of a Linux virtual machine.
The project focuses on understanding how a server works behind the scenes and how to apply good security practices.

## 🖥️ What You Will Build
- A virtual machine using **Debian** or **Rocky Linux**
- A secure server with a strong password policy
- Proper user and group management
- A firewall configured with **UFW** or **firewalld**
- Secure **SSH** access running on port `4242`
- Automated tasks using **cron**
- A lightweight system-monitoring script

## 🔐 Core Concepts You Learn
- Installing and configuring a Linux OS from scratch  
- Understanding partitions, LVM, and filesystem layout  
- Managing privileges, users, and groups safely  
- Hardening a server using real security guidelines  
- Enabling and configuring key services (SSH, firewall, sudo)  
- Basic monitoring and maintenance of a running system  

## 📝 Tips for the Project
- Read your OS documentation as you go — it’s your best resource.  
- Keep notes on every command and setting you modify.  
- Test your configuration often to avoid surprises during evaluation.

## ✅ Goal
By completing Born2beRoot, you gain a strong foundation in Linux administration, security, and server management — skills you’ll reuse throughout many future projects.
